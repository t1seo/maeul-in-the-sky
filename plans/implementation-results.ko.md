# 마을 개선 구현 및 검증 기록

2026-09-13. Orca 실행: `run_30a2455d97f5`. 기준 커밋: `c6d60487e50347fd84b770b57618d181acd874de`.

현재 상태: 계획에서 채택한 개선 사항의 구현과 검증을 완료했습니다. Orca의 구현·검증·독립 검토·수정 루프를 거쳐 최종 다섯 검토가 모두 통과했습니다. 확정된 코드에서 1,170개 테스트·커버리지·타입·린트·포맷·빌드·설치 패키지 검사가 통과했습니다. 새 CSS 사례 78개와 기존 선택자·XML·SMIL·모바일 확대도 실제 빌드로 확인했으며, 검토 종료 후 소스·테스트·출시 산출물 20개의 해시가 검토한 버전과 일치하는 것을 확인했습니다.

## 구현한 기능

- 실제 UTC 날짜에 맞는 부분 주·누락 날짜·윤년 배치, 낮과 밤이 공유하는 결정적 장면, 날짜 기반 에셋 식별자.
- 배너와 카드, 읽기 쉬운 외부 통계·범례, 터치 핀치 확대·이동·키보드 탐색, 날짜별 설명, 낮/밤 배경.
- `full`·`subtle`·`off` 모션과 모션 감소 환경의 정적 장면, 정적 PNG 내보내기.
- 프레임워크 없이 동작하는 브라우저 렌더러와 별도 npm 진입점, 설정 링크와 JSON, 스냅샷 가져오기·내보내기.
- 읽기 권한의 생성 작업과 쓰기 권한의 게시 작업을 분리한 GitHub Action 워크플로 및 README 생성기, 로컬 토큰 환경변수를 사용하는 인증 미리보기 서버.
- Wonder 30종의 도감·발견 조건, 같은 높이 기준을 사용하는 연도별 보관·비교.
- 기존 일반 에셋 189종과 한옥·정자·돌담·옹기 4종, 조건에 맞는 이웃길·데크, 실제 기여량을 유지하는 저활동 장면.
- CLI·Action·Node API의 새 설정 및 스냅샷·아카이브·PNG 지원. PNG용 WASM, 한글 글꼴과 라이선스 포함.
- API 입력·응답 검증, 유형별 오류, 제한된 재시도·시간 제한, 미리보기 서버의 Host/Origin·경로·캐시 제한.
- 팔레트 캐시, 공통 장면 준비, 수치 직렬화, 생성 예제에만 적용하는 검증된 SVG 최적화.

일반 에셋 193종과 Wonder 30종을 검색하고 계절·종류·스타일·명암으로 거르는 카탈로그도 제공하며, 자동 재생성과 목록 일치 검사를 CI에 연결했습니다. 입력은 `style`과 `villageStyle`을 함께 지원하고 기존 v1 저장 형식을 유지합니다. 모바일 확대는 표시 중인 지형을 중심에 배치하고 버튼·키보드 확대의 초점을 유지합니다. 사용자 정의 SVG 비교는 네임스페이스·문자 참조·한글과 이스케이프된 CSS 선택자를 해석해 색상 참조와 SMIL 대상을 각 행의 요소에 연결합니다. 로컬 CSS 선택자는 해당 연도 행에 적용하며 원래 ID 유무와 선택자 우선순위를 유지합니다. 외부 스타일시트와 키프레임·글꼴 등의 전역 이름은 완전히 격리하지 않으므로 사용자 정의 테마에서 고유한 이름과 자체적으로 완결된 스타일을 사용해야 합니다. XML 선언과 DOCTYPE은 중첩 전에 제거하며, 외부 DTD와 사용자 정의 엔티티는 불러오지 않습니다. 잘못된 입력은 아카이브 파일을 쓰기 전에 오류로 반환합니다. 아카이브는 선택하지 않은 저장본을 보존하며, 유효한 XML 문자와 연도 1–9999의 날짜 경계도 검증합니다.

기본 아카이브의 연도별 SVG·스냅샷·목록 7개 파일은 기존 출력과 바이트가 같고, CSS 범위가 추가된 비교 SVG 2개는 세 브라우저의 낮·밤 6개 이미지가 수정 전과 정확히 같았습니다.

표의 246개 브라우저·3개 승인 이미지·벤치마크 검사는 CSS·XML 및 Action 패키징 보완 직전의 결과입니다. 보완 후 전체 화면·브라우저 번들·이미지·해당 테스트·렌더러와 실행 환경이 동일함을 해시와 버전으로 확인해 적용했습니다. 전체 단위 테스트·설치 패키지·아카이브 호환성·보안 검사는 보완된 코드에서 새로 실행했습니다. 새 CSS 78개 사례와 기본 비교 화면 6개 이미지 검사도 세 브라우저에서 새로 실행한 결과입니다.

CI에는 Linux 브라우저 검사, macOS 승인 이미지 비교, 패키지 실행, 커버리지와 성능 기준 검사를 연결했습니다. 호스팅된 GitHub Actions 실행 결과는 로컬 검증과 구분하며, 이번 작업에서 배포나 원격 CI 실행을 수행하지 않았습니다.

## 성능과 크기의 실제 변화

같은 Apple M1·Node 26.8.1에서 같은 고정 입력을 20회 예열한 뒤 100회의 낮/밤 SVG 쌍 생성을 측정했습니다. 측정 대상은 지형 렌더러의 동기 실행입니다. 네트워크·파일 쓰기·PNG 변환과 아카이브의 XML·CSS 합성 비용은 포함하지 않았습니다. 공유 컴퓨터에서 관찰한 결과이며 모든 기기에서의 속도를 보장하지 않습니다.

| 입력        | 변경 전 중앙값 | 변경 후 중앙값 |          변화 |
| ----------- | -------------: | -------------: | ------------: |
| 활동 없음   |        16.58ms |        14.14ms | 약 14.7% 단축 |
| 혼합 활동   |        18.16ms |        18.29ms |  약 0.7% 증가 |
| 고밀도 활동 |        18.97ms |        22.40ms | 약 18.1% 증가 |

정적 대체 장면과 날짜 메타데이터가 추가되면서 고밀도 입력의 생성 시간과 기본 full SVG 크기가 증가했습니다. 고밀도 dark 출력은 약 1.08MB 원본·143KB gzip입니다. 모션이 필요 없는 경우 `off`를 사용할 수 있습니다.

별도 팔레트 실험에서는 반복 계산이 약 5배 빨라졌으며 기존 색상 체크섬이 일치했습니다. SVG 생성 예제용 최적화는 검증한 6개 입력에서 gzip 크기를 16.54–17.06% 줄였으나, SVG당 77–235ms의 추가 오프라인 처리 비용과 작은 서브픽셀 차이가 있습니다. 실시간 렌더러에는 적용하지 않았고, 실장면에서 이득이 작은 `defs/use` 실험도 채택하지 않았습니다. 물 밝기를 미리 계산하는 실험은 원본 크기를 약 0.6% 줄였지만 gzip이 늘고 픽셀이 달라져 채택하지 않았습니다.

원시 기준선과 샘플은 [benchmark-baseline.json](../tests/fixtures/benchmark-baseline.json)에 있습니다. 세부 실행 영수증과 실제 스크린샷은 로컬 `.orca/maeul-improvements/evidence/` 및 `evidence/`에 보관합니다.

## 실행

새 기능은 현재 작업트리의 Unreleased 변경입니다.

```sh
npm install
npm run build
node dist/index.js --help
node dist/index.js preview --port 4318
```

로컬 미리보기의 실제 계정 조회에는 서버 환경의 `GITHUB_TOKEN`이 필요합니다. 브라우저에 토큰을 입력하거나 저장하지 않습니다. 스냅샷 가져오기는 인증 없이 사용할 수 있습니다.

커밋·푸시·태그·릴리스·배포는 수행하지 않았습니다. 실행 계획은 [maeul-improvement-implementation.md](maeul-improvement-implementation.md), 조사 근거는 [프로젝트 개선 리서치](project-improvement-research-2026-09-13.ko.md)를 참고하실 수 있습니다.
