## 검토에서 발견한 내용

- `CHANGELOG.md` 누락을 보완해 232종·독립 그림체·기여 단계·layout v2·장식 설정 의미·새 성능 기준을 기록했습니다.
- 성능 표의 이전 gzip 세 값을 연결된 동일 Node 26.0.0 측정 자료의 68,257 / 99,618 / 145,825 B로 바로잡았습니다. 원본 측정 JSON, 이후 수치와 처리 시간은 변경하지 않았습니다.
- `CLAUDE.md`의 일반 193종·한국형 4종 표기를 현재 202종·13종으로 갱신하고 두 그림체와 생성물 확인 절차를 추가했습니다.
- 보안의 비차단 권고는 공개 예제의 가변 `@main` 참조입니다. 기존 npm 1.4.0/v1이 새 입력을 지원하지 않음을 명시하고 전체 SHA 고정을 안내합니다. 실제 사용자 프로필에는 검증한 병합 SHA를 고정합니다.

기존 Wonder 상세 설명의 중복 마침표(`7 days..`)는 비차단 문구 문제로 기록했습니다. 이번 에셋 변경 전부터 같은 상태이며 기능·조건·날짜 의미에 영향을 주지 않습니다. 정적 서버의 미지원 API/파비콘 404와 제품의 브라우저 예외를 구분했고, 직접 사용 중 `pageerror`는 0건이었습니다.

아트의 주관적 우열은 자동 검사의 보증 대상이 아닙니다. 검토자는 확대 비교와 실제 연간 카드의 명암·실루엣·계절 구분을 직접 관찰했고, 전수 변경·알파 경계·도달성은 관련 테스트와 통합 증거를 함께 검토했습니다. 원본 count 보상은 일별 단계와 주 결과물에 관한 보장이며 전체 장면의 그림 면적이나 Wonder 개수가 항상 증가한다는 의미가 아닙니다.
