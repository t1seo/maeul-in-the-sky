# 자연 경관·다양성 개선 검증 기록

기준 버전은 `c55a77b012e087ad0ec1e591e68983dbfcb911df`입니다. 이번 변경은 자연물 중심의 구성, 같은 실루엣의 반복 완화, 꾸준한 기여에 따른 계절 효과를 대상으로 합니다.

## 설계와 조사 근거

[실행 계획](nature-composition-2026-09-19.md)과 [1차 자료 조사](nature-composition-research-2026-09-19.ko.md)에 근거와 선택한 계약을 기록했습니다. 일반 기여 단계와 꾸준함 보상은 별도로 계산합니다. 새 런타임 의존성은 추가하지 않습니다.

변경 전 데모는 일반 주 에셋 268개 중 돛단배가 26개였습니다. 독립 측정에서는 수역의 10–24회 보상이 항상 돛단배, 한국식 육지의 50회 이상 보상이 항상 한옥 대저택으로 선택되었습니다. 전체 카탈로그의 개수보다 선택 풀이 실제 반복을 만드는 원인이었습니다.

## 비교 입력

- 데모: 저장소의 고정 시드 표본, 1,582 기여.
- 프로필 비교: 기존 공개 SVG의 날짜별 보상 수치를 복원한 동일 입력, 2025-09-18–2026-09-18, 총 4,309 기여와 활동일 268일. 새로운 배포에서 갱신된 실제 데이터와 혼동하지 않습니다.
- 합성 대조: 각 기여 단계, 동일 총합의 집중/분산 활동, 0회·누락일, 사계절·양반구, 두 문화·두 그림체.

## 변경 내용

- 자연 경관 8종과 각 3개 형태: 삼나무 숲, 고목, 야생화 초원, 대나무 덤불, 연꽃 연못, 갈대 습지, 고산 바위, 버드나무 연못.
- 기존 돛단배에도 실제로 다른 돛 형태 3개를 적용했습니다. 실루엣 래스터 테스트를 먼저 실패시킨 뒤 수정했고, 기존 경계를 유지했습니다.
- 후보는 문화 변환 후 중복을 제거하고, 건축물과 배는 드문 지점에 배치합니다. 날짜 기반 공간 규칙으로 반복을 줄이며 실제 다른 날짜의 기여량을 읽어 주 에셋을 재추첨하지 않습니다.
- 꾸준함은 해당 날짜를 포함한 최근 28일의 알려진 활동일 5·12·20일을 기준으로 합니다. 관측일 수를 별도로 기록하고, 정적 출력에도 계절 보상을 남깁니다.
- 신규 장면은 layout v3입니다. 이전 준비된 v1/v2 장면은 계속 렌더링하지만 스냅샷을 다시 생성하면 새 시드에 따라 지형·에셋·Wonder 배치가 바뀝니다.
- 프리셋 설명을 실제 동작인 추가 장식량에 맞췄습니다. 밀도가 주 에셋의 종류나 일별 보상을 바꾼다고 설명하지 않습니다.
- 높이 범례는 동일 기준선에서 높아지는 중립 회색 막대로 변경했습니다. 계절색이 기여 단계처럼 보이는 혼동을 줄였습니다.
- 일별 주 에셋과 꾸준함 효과는 실제 월과 반구를 따릅니다. 1월 중순에 봄꽃을 선택하던 전환 구간 문제를 수정하며 지형색의 점진적인 변화는 유지합니다.
- 모션 출력의 정적 에셋 도형은 SVG 내부 symbol로 재사용합니다. 한 분기만 필요한 motion off에서는 인라인 도형을 유지해 참조용 부가 용량을 피합니다. 날짜별 선택 영역과 애니메이션 정책을 유지하며, 그림체별 래스터 비교로 출력의 동등성을 검사합니다. 외부 파일을 참조하지 않습니다.

## 성능

기존 벤치마크 입력·기준 파일과 +5% 원본/압축/노드, +20% 중앙값, +30% p95 제한을 그대로 유지했습니다. 첫 통합에서는 다양성 증가로 최대 활동량 SVG가 한도를 초과했지만, 정적 도형을 내부 symbol로 공유해 통과했습니다. 미니어처·픽셀의 재사용/인라인 렌더 픽셀 비교를 검사합니다.

| --- | --- | --- | --- |
| Empty | 517,900 → 495,474 B | 70,161 → 68,624 B | 5,552 → 5,422 |
| Mixed | 945,057 → 877,204 B | 134,798 → 114,773 B | 10,606 → 9,766 |
| Full | 1,742,317 → 1,546,209 B | 170,890 → 159,468 B | 19,509 → 16,750 |

같은 호스트에서 이번 작업 직전 측정한 중앙값은 empty/mixed/full 15.17/22.74/30.93ms, 최종 개선 후 15.36/24.21/31.93ms였습니다. 개선 후 p95는 17.07/25.52/33.74ms였습니다. Node26·macOS·Apple M1의 공유 호스트 측정이며, 다른 작업과 동시에 실행한 측정은 별도 기록하고 최종 시간 검사는 순차 실행했습니다. 저장소의 고정 기준과 양 모드의 모든 크기·시간 제한을 통과했습니다. 최종 소스 SHA-256은 `17f521292137f45fae129c174cc8d4d8948a98dac8f3d1ef77cd75c5045656af`이며 측정 도중 바뀌지 않았습니다.

## 의미와 한계

카탈로그는 이전 장면과 직접 렌더링용 에셋도 보존합니다. 내륙 경관을 우선하는 새 일별 선택에서는 고래·갈매기·해초·산호·게·운하 같은 일부 기존 에셋이 출현하지 않으므로, 210종 전체가 매년 생성된다는 의미는 아닙니다. 기존 Wonder의 상대 활동량 조건에 따라 정규화 설정 변경 시 일부 날짜의 일반 에셋과 Wonder가 교체될 수 있습니다.

기여 수는 GitHub가 집계한 활동이며 코드 품질·노동 시간의 평가가 아닙니다. 꾸준함은 연속 출석이 아니며 하루 쉬어도 기존 주 에셋을 없애지 않습니다. 날짜별 주 에셋 독립성을 유지하므로 다른 기여 단계나 생태 경계에서 인접 반복을 완전히 없앤다는 보장은 하지 않습니다. 효과와 Wonder의 전역 개수 제한 때문에 표시할 지점은 관측 범위가 달라지면 재배정될 수 있습니다.
