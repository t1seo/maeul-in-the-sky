## 지키는 데이터와 모션 계약

- 기여 날짜와 수치를 그대로 보존하며, 관측된 0회와 미관측 날짜를 구분합니다. 일별 전체 기여를 특정 저장소의 기여로 추정하지 않습니다.
- 재생 날짜가 바뀌어도 이미 만들어진 위치는 유지합니다. 미래 날짜의 보상·통계·발견은 앞서 보여주지 않습니다.
- 세계의 모션을 끄거나 줄이면 현재 시간과 포즈를 보존합니다. 저장된 정지 장면을 다시 열 때에도 강물과 카메라의 시점을 복원합니다.
- 세계 JSON은 최대 8 MiB, 스냅샷·아카이브는 최대 2 MiB입니다. 세계는 경계·미관측 날짜를 포함한 최대 800일, 로컬 보관함은 최대 20개 저장본을 지원합니다. 모델 부품과 지형·경로의 실제 확장 비용도 제한합니다.
- 공개 주소에는 HTTPS GitHub raw·Pages를 사용하고 브라우저에 토큰을 입력하거나 저장하지 않습니다. 가져오기나 네트워크 작업이 실패하면 현재 세계를 유지합니다.
- 기존 CLI·Action·브라우저 SVG API는 Three.js를 가져오지 않습니다. WebGL을 사용할 수 없으면 2D 지도를 유지합니다.

## 검증 기록

최종 소스의 타입·린트·포맷, 전체 빌드와 생성 산출물 복사를 통과했습니다. 새 배치의 모델·데이터 검사 662개, 관련 UI 소스 검사 29개, 지도 검사 22개와 실제 데스크톱·모바일 배치 시나리오 8개도 통과했습니다. 클래식의 비동기 전환 중 입력 초안 보존과 3D 키보드 탐색 수정은 집중 검사 64개 및 오르카의 실제 사용으로 확인했습니다.

전체 커버리지, 9개 브라우저 환경, 설치 패키지, 정적 승인 이미지와 렌더링 예산은 최종 커밋의 CI에서 확정합니다. 중단한 로컬 전체 커버리지 실행은 통과로 집계하지 않습니다. 로컬 3D 열 번 전환 시나리오는 실제 자원 해제 검사를 유지하면서 소프트웨어 GPU의 누적 실행 제한을 120초에서 240초로 조정해 재검증합니다. 개별 생성 30초 제한과 프레임·형상·크기·커버리지 기준은 유지합니다. 모든 필수 CI와 다섯 관점의 최종 검토를 통과한 뒤 병합·배포합니다.

검증에는 날짜·계절·반구·경로·저장 문서의 단위 검사, 실제 브라우저의 저장·방문·재생·다운로드·모바일 조작, 생성 SVG의 독립 렌더링, GLB 재파싱, 반복적인 3D 진입·종료 후 자원 해제, 기존 프로필 SVG의 크기·렌더링 예산을 포함합니다. 기존 커버리지와 성능 제한은 유지합니다.

새 배치는 독립 CPU 검사 48개 경우에서 지면의 실제 연결과 날짜·좌표 보존을 확인했습니다. 연간 지면의 연결된 덩어리는 월별 군도 12개, 큰 섬 1개, 사계절 군도 4개입니다. 기존 두 배치의 직렬화 결과는 변경 전과 바이트가 같습니다. 같은 366일 입력에서 사계절 군도의 지면·절벽은 8,400개 삼각형으로 큰 섬의 8,424개 이내이며, 이는 전체 장면의 GPU 삼각형 수와 구분합니다. 793일·26개월의 남반구 세계도 2,822,458바이트 JSON으로 저장·복원했습니다. [배치 측정 원본](sky-world-evidence/seasonal-layout-metrics.json)을 남겼습니다.

## 3D 성능 측정

Apple M1의 실제 Metal GPU를 쓰는 headed Chromium에서 다른 작업용 브라우저·테스트를 멈추고 측정했습니다. 입력은 366일·1,001개 오브젝트, 높은 품질, 화면 800×500 CSS px와 1600×1000 drawing buffer입니다.

| 지형 | 초기 생성 | RAF 간격 중앙값 / p95 | 전체 뷰 draw calls / triangles |
| --- | ---: | ---: | ---: |
| 월별 군도 | 424 ms | 16.8 / 17.8 ms | 148 / 368,078 |
| 하나의 섬 | 286 ms | 16.7 / 18.1 ms | 148 / 414,530 |

[원본 측정값](sky-world-evidence/native-performance.json)은 각 지형의 24프레임 관측입니다. 브라우저 프레임 간격으로 약 60Hz의 갱신을 확인한 것이며 GPU 타이머 측정이나 모든 기기에서의 성능 보장은 아닙니다. 두 번째 지형은 드라이버 캐시의 영향을 받을 수 있습니다. 코드 커버리지를 계측하는 headless 소프트웨어 렌더링의 시간과 구분합니다.

## 기존 프로필 SVG의 예산

기준 커밋과 같은 입력으로 empty/mixed/full × banner/card를 비교했습니다. 20회 예열 뒤 각각 100회 교대로 렌더링한 최종 격리 측정은 여섯 조합 모두 기존 중앙값 +20%, p95 +30% 제한을 통과했습니다. 최대 중앙값 비율은 1.1040, 최대 p95 비율은 1.2366입니다. [측정 원본](sky-world-evidence/svg-timing.json)을 남겼습니다.

다크·라이트를 포함한 12개 조합에서 raw/gzip/XML 요소 수의 기존 +5% 제한을 지켰습니다. 최대 이전 대비 비율은 각각 0.9507/0.7995/0.9386입니다. 실제 프로필 시드에서 발견한 52개 애니메이션은 남은 효과 예산을 계산해 50개 이하로 제한했고, 최적화 전후 도형은 [바이트 단위 비교](sky-world-evidence/svg-equivalence.json)로 유지됨을 확인했습니다. 효과 집계는 실제 필요한 속성만 읽도록 바꿨으며 픽셀 그림체의 지형 표현은 보존합니다.
