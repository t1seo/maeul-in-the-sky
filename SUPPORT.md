# Support

Start with the [README troubleshooting guide](README.md#troubleshooting). It covers workflow permissions, usernames, date ranges, reduced motion, and private contribution visibility.

For a usage question or reproducible bug:

1. Check the latest release and existing issues.
2. Run the workflow again with `workflow_dispatch` and inspect its log.
3. Open the matching [issue form](https://github.com/t1seo/maeul-in-the-sky/issues/new/choose).

Include the package or Action version, runtime, relevant inputs with secrets removed, the full error message, and a minimal reproduction. Security problems belong in [private vulnerability reporting](SECURITY.md), not a public issue.
