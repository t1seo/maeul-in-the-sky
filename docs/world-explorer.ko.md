# 하늘 세계 탐험기

[탐험기 열기](https://t1seo.github.io/maeul-in-the-sky/world/) · [English guide](world-explorer.md)

기여 기록의 하루하루가 하늘에 떠 있는 미니어처 세계의 장소가 됩니다. 샘플로 시작하거나 스냅샷·여러 해 아카이브를 가져오실 수 있습니다. 기존 데모의 **Explore your world**를 누르면 현재 보고 계신 기록이 탐험기로 이어집니다.

## 보기 버전 선택

탐험기의 **보기 버전**에서 같은 원본 기록을 최신 SVG 또는 업데이트 이전의 **클래식 SVG**로 여실 수 있습니다. [클래식 바로 열기](https://t1seo.github.io/maeul-in-the-sky/?renderer=classic)도 지원합니다. SVG 데모의 선택은 공유 주소에 남으며 미리보기와 이미지 내보내기에 함께 적용됩니다.

클래식 버전은 `05a10eff07575acf2c81adcd66a66bc501507217`의 브라우저 렌더러를 그대로 보관한 것입니다. 건축 문화의 `classic` 설정과는 별개입니다. 클래식에서 생성하는 GitHub 워크플로는 해당 커밋에 고정되고 최신 버전은 `main`을 따릅니다. 스냅샷 JSON에는 기존처럼 기록과 설정을 보관하므로, 프로필 디자인을 특정 버전으로 유지하시려면 생성된 워크플로의 커밋 지정을 유지해 주세요.

## 둘러보고 되돌아보기

- **월별 군도 / 하나의 큰 섬 / 사계절 군도**를 선택하실 수 있습니다. 큰 섬은 1월부터 12월까지의 땅을 이어 붙이고 월마다 계절 풍경을 유지합니다. 사계절 군도는 봄·여름·가을·겨울에 해당하는 달을 각각 모읍니다. 북반구의 겨울에는 12·1·2월이 포함되며, 남반구에서는 계절 구분이 6개월 바뀝니다. 일부 기간만 불러오면 그 기간에 포함된 계절의 섬이 나타납니다.
- 각 날짜의 기록과 배경 경관은 구분됩니다. 최근 1년 기록처럼 서로 다른 연월이 13개인 기간도 그대로 보존합니다. 배치를 바꾸어도 기여 기록과 날짜순 타임라인은 유지되며, 세계 파일과 로컬 저장에 선택한 배치가 보관됩니다. 계절 미리보기는 풍경을 바꾸며 섬의 묶음은 바꾸지 않습니다.
- **Four-season circle**은 하나의 둥근 천공의 섬을 봄·여름·가을·겨울 풍경으로 나눕니다. 해안으로 이어지는 강은 섬 아래 하늘로 떨어지는 폭포가 됩니다. 기록이 없는 계절은 배경 풍경으로 표시하며, 실제 기여 수나 날짜를 추가하지 않습니다.
- SVG 지도와 실제 3D를 전환하실 수 있습니다. 3D에서는 드래그로 회전하고 휠이나 두 손가락으로 확대합니다. 월·날짜·움직이는 주민을 따라가거나 전체 세계로 돌아오실 수 있습니다.
- 날짜를 움직이거나 재생하면 지나온 기록이 순서대로 드러납니다. 통계·발견·활동 보상도 해당 날짜까지만 반영됩니다.
- 봄·여름·가을·겨울, 낮·노을·밤과 날씨를 감상하실 수 있습니다. 감상 설정은 실제 기여 수를 바꾸지 않습니다. 모션은 줄이거나 끄실 수 있습니다.

날씨의 **계절 따라** 설정은 각 달의 계절을 따릅니다. 꽃잎과 나비, 여름의 가벼운 비, 가을 낙엽, 겨울 눈이 월별 풍경을 구분해 줍니다. 맑음·비·눈을 직접 고르거나 계절을 미리 감상하실 수도 있습니다. 강의 잔물결과 물가, 잔디·흙·모래·바위는 가까이에서 세부를 보실 수 있습니다.

자연이 중심을 이루고 마을과 도시가 작은 구역으로 어우러집니다. 하루의 활동은 장소의 세부를 키우고 꾸준한 활동은 계절 행사와 불빛, 움직임을 더합니다. 나무와 건물, 경관에는 서로 다른 형태를 섞습니다.

## 저장·방문·기념품

세계는 이 브라우저에 저장하거나 JSON 파일로 내려받으실 수 있습니다. 세계 파일에는 완성된 배치와 원본 스냅샷, 카메라를 포함한 감상 설정이 담깁니다. 세계 파일은 최대 8 MiB, 기존 스냅샷·아카이브는 최대 2 MiB이며, 브라우저에는 최대 20개 저장본을 보관합니다.

한 세계는 관측되지 않은 날짜와 시작·끝 달의 경계를 포함해 최대 800일을 다룹니다. 더 긴 기록은 연도별 스냅샷으로 나누어 여러 세계의 아카이브로 가져오실 수 있습니다. 기간을 넘으면 일부 날짜를 버리는 대신 제한을 안내합니다.

모델과 지형의 전체 복잡도도 확인합니다. 너무 세밀한 세계는 현재 화면을 유지한 채 안내하므로, 기간이나 프로젝트 기념물을 줄여 다시 저장해 주세요.

방문 즐겨찾기와 발견 일지는 이 브라우저에 별도로 남습니다. 사이트 데이터를 지우면 로컬 기록도 사라질 수 있으므로 오래 보관할 세계는 파일로 내려받아 주세요.

다른 분께 보여드리려면 JSON을 GitHub Pages나 공개 저장소에 게시한 뒤, Pages 또는 raw GitHub의 HTTPS 주소를 탐험기에서 여시면 됩니다. 공유 링크는 공개 파일을 가리키며 로컬 데이터를 자동으로 업로드하지 않습니다. 방문한 세계를 즐겨찾기에 넣거나 원래 세계로 돌아오실 수 있습니다.

프로젝트 구역에는 GitHub에서 읽은 공개 저장소와 릴리스 정보를 사용합니다. 전체 일별 기여를 특정 저장소의 기여로 추정하지 않습니다. API 요청 제한과 일부만 조회된 결과는 화면에 표시하며, 불러오기에 실패해도 현재 세계를 유지합니다.

지도는 PNG와 독립 실행형 SVG, 3D는 PNG와 GLB로 저장하실 수 있습니다. GLB에는 실제 입체 형상과 재질이 들어갑니다. 화면의 애니메이션 녹화나 3D 프린팅 적합성 검증을 포함하는 파일은 아닙니다.

## 실행 환경

WebGL 2를 사용할 수 없는 환경에서도 지도는 이용하실 수 있습니다. 3D 엔진은 3D를 선택할 때 불러옵니다. 넓은 화면에서 세계의 세부를 가장 편하게 감상하실 수 있으며, 모바일과 모션 축소 설정도 지원합니다.

소스 체크아웃에서는 `npm ci`, `npm run build`, `node dist/index.js preview`를 순서대로 실행한 뒤 표시되는 주소를 열어 주세요. **Explore your world**에서 Pages와 같은 탐험기를 여실 수 있습니다. 기존 CLI·Action·브라우저 렌더링 API는 Three.js를 불러오지 않고 SVG를 생성합니다.

이번 탐험기는 `main`과 Pages에 반영됩니다. npm `1.4.0`과 이전 `v1` Action 태그에는 포함되지 않으므로 README의 소스 체크아웃 또는 검증된 커밋 사용 안내를 따라 주세요.

## GitHub 프로필에 3D 섬 표시하기

GitHub README에는 실제 Three.js 장면을 촬영한 밝은 테마·어두운 테마 PNG를 표시하고, 이미지를 클릭하면 같은 세계의 인터랙티브 3D 화면으로 이동하도록 연결할 수 있습니다. README 안에서 직접 회전하는 방식은 아닙니다.

선택형 `t1seo/maeul-in-the-sky/profile` Action을 기존 스냅샷 생성 단계 뒤, 파일 커밋 단계 앞에 추가하시면 됩니다. 같은 원본 기록에서 `maeul-in-the-sky-world.json`과 두 PNG를 함께 생성하며, 촬영에 실패하면 이전에 게시된 파일을 유지합니다. [설정 예시와 실행 명령](world-explorer.md#show-a-3d-island-on-your-profile)을 참고해 주세요.

세계 링크에 `&view=three`를 추가하면 처음부터 3D로 열립니다. 3D를 지원하지 않는 기기에서는 같은 기록의 지도로 전환됩니다.
